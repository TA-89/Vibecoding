# Bilder fuer das Vibecoding-Deck

Die Seite funktioniert auch ohne diese Bilder. Wenn eine Datei fehlt, erscheint ein gestalteter Platzhalter.

Empfohlene Dateien:

- `hero-bg.jpg` - Titel-Hintergrund, Querformat 16:9 oder 3:2, ca. 2000 px breit.
- `screenshot-claude.png` - Screenshot Claude/Claude Code, Querformat.
- `screenshot-codex.png` - Screenshot OpenAI Codex, Querformat.
- `screenshot-google.png` - Screenshot Google AI Studio oder Antigravity, Querformat.
- `screenshot-beispiel.png` - optionaler Screenshot fuer ein Unterrichtsbeispiel.

Bitte keine personenbezogenen Daten sichtbar lassen.
