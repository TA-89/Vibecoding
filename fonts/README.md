# Lokale Schriften

Im Prompt sind Space Grotesk, DM Sans und JetBrains Mono gewuenscht.

In dieser ersten Version sind keine Font-Dateien beigelegt, damit keine erfundenen oder ungeprueften Dateien im Projekt liegen. Die Seite nutzt robuste System-Fallbacks und bleibt offline lauffaehig.

Wenn die Schriften spaeter lokal ergaenzt werden:

- `SpaceGrotesk.woff2`
- `DMSans.woff2`
- `JetBrainsMono.woff2`

Danach koennen passende `@font-face`-Regeln in `style.css` ergaenzt werden.
