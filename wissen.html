Gratis online stellen

Eine einfache Webseite mit GitHub Pages veröffentlichen.

Für HTML, CSS, JavaScript und Bilder genügt ein kostenloses GitHub-Konto.

01

Projekt anlegen

Ein öffentliches Repository erstellen.

02

Dateien laden

Projektdateien und Bilder hochladen.

03

Pages einschalten

Unter «Settings → Pages» den Branch main wählen.

04

Link testen

Die neue github.io-Adresse öffnen.

Wichtig: GitHub Pages ist öffentlich und für statische Seiten gedacht. Keine Lernendendaten oder privaten Fotos hochladen. PHP, Datenbanken und geschützte Uploads brauchen einen passenden Webserver.

Mögliche Werkzeuge

Wähle eines und starte mit einer kleinen Aufgabe.

OpenAI Codex ↗Arbeitet direkt mit Dateien und führt Tests aus. Lovable ↗Erstellt WebApps aus einer Beschreibung. Bolt ↗Baut Prototypen direkt im Browser. v0 ↗Hilft beim Erstellen von Oberflächen.

Sicher arbeiten

Prüfen ist wichtiger als alles blind zu verstehen.

  1. Keine sensiblen Daten in öffentliche Projekte laden.
  2. Links, Eingaben, Uploads und Löschfunktionen selbst testen.
  3. Vor Änderungen einen funktionierenden Stand sichern.
  4. Bei Datenschutz oder Sicherheit Unterstützung holen.
