Für Lehrpersonen

Aus einem Unterrichtsproblem wird ein eigenes Werkzeug.

Beim Vibecoding beschreibst du in normaler Sprache, was eine digitale Lösung können soll. Eine KI erstellt die Dateien. Du probierst die Lösung aus und beschreibst die nächste Verbesserung.

Die Kurzdefinition

Idee erklären → erste Version erhalten → testen → verbessern.

Du musst dafür nicht zuerst programmieren lernen. Du musst aber verstehen, was veröffentlicht wird und welche Daten verwendet werden.

So funktioniert es

Vier Schritte, die sich wiederholen.

01

Beschreiben

Problem, Zielgruppe und den gewünschten Ablauf in eigenen Worten erklären.

02

Generieren

Die KI erstellt oder verändert HTML, CSS, JavaScript und weitere Dateien.

03

Ausprobieren

Öffnen, klicken und prüfen, ob das Werkzeug im echten Unterricht verständlich ist.

04

Verbessern

Eine konkrete Änderung beschreiben und den Kreislauf erneut durchlaufen.

Ein guter Einstieg

  • kleines, echtes Unterrichtsproblem
  • klarer Ablauf
  • wenige Funktionen
  • schnell testbar

Noch kein guter Einstieg

  • Notenverwaltung
  • sensible Personendaten
  • kritische Sicherheitsfunktionen
  • ein riesiges System auf einmal

Ein guter Prompt

Beschreibe nicht den Code. Beschreibe das Werkzeug.

1

Ziel

Welches Problem soll einfacher werden?

2

Personen

Wer benutzt das Werkzeug und auf welchem Gerät?

3

Ablauf

Was wird eingegeben, angeklickt und angezeigt?

4

Regeln

Was darf auf keinen Fall passieren?

Erstelle mir einen einfachen Gruppengenerator für meinen Unterricht.

Ich füge die Vornamen ein und wähle die Anzahl Gruppen. Die Namen werden zufällig und möglichst gleichmässig verteilt. Niemand soll am Schluss allein in einer Gruppe sein.

Die Seite muss auf dem Handy gut funktionieren. Erstelle zuerst eine kleine Version und erkläre mir danach kurz, welche Dateien du erstellt hast.

Gratis ausprobieren

Eine einfache Webseite mit GitHub Pages veröffentlichen.

Für HTML, CSS, JavaScript und Bilder reicht ein öffentliches GitHub-Repository. Es ist kein eigener Webserver nötig.

01

Konto

Ein kostenloses GitHub-Konto erstellen.

02

Repository

Ein neues öffentliches Projekt anlegen.

03

Dateien

index.html, CSS, JavaScript und Bilder hochladen.

04

Pages

Unter «Settings → Pages» die Veröffentlichung aus dem Branch main aktivieren.

05

Link

Den erzeugten github.io-Link öffnen und testen.

Wichtig: GitHub Pages veröffentlicht statische Webseiten. PHP, Datenbanken und geschützte Uploadbereiche benötigen einen richtigen Webserver. Lade keine Lernendendaten oder privaten Fotos in ein öffentliches Repository.

Sicher arbeiten

Fünf Regeln, die wichtiger sind als perfekte Codekenntnisse.

  1. Keine sensiblen Lernendendaten in öffentliche Projekte laden.
  2. Jeden Link, Upload und Löschvorgang selbst testen.
  3. Nur die wirklich benötigten Zugriffsrechte vergeben.
  4. Vor grösseren Änderungen einen funktionierenden Stand sichern.
  5. Bei Unsicherheit Datenschutz, IT oder eine fachkundige Person einbeziehen.
